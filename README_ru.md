## Что это

**Hiring Radar — инструмент данных о найме, созданный для ИИ: он позволяет вашему ИИ (Claude Code / Codex / ChatGPT / любому агенту) читать официальные открытые вакансии компаний по всему миру и в Китае.** Он читает системы управления наймом (ATS) компаний и публичные источники вакансий через их открытые интерфейсы и превращает вакансии в **структурированные данные с едиными полями**. Работает локально; одна команда — и вы получаете вакансии компании, страны или функции, **без аккаунта и без настройки**.

Три сценария:

- 🔎 **Поиск работы / «кто сейчас нанимает?»**: какие компании нанимают в нужной области, в каких городах и с какой зарплатой.
- 📊 **Исследование рынка / продуктовые возможности**: выгружать целые срезы по стране, функции и периоду, чтобы увидеть, за что рынок платит людям (новое в v2).
- 📈 **Опережающий отраслевой / инвестиционный сигнал**: найм часто раскрывает стратегию за месяцы до отчётности. См. «Отраслевой сигнал» ниже.

**Крупные мировые бренды находятся по одному названию компании**, например NVIDIA · OpenAI · Anthropic · Stripe · Databricks · Coinbase · Reddit · Discord · Cloudflare · Notion · Scale AI · Figure · Perplexity · 1X · Cohere · GitLab и другие.

**Новое в v2**: 24 ATS и справочник примерно 90 000 компаний (по названию видно, какой системой пользуется компания) · 12 межкомпанийных источников (в том числе агрегатор freehire и государственные базы вакансий Швеции, Сингапура и Германии) · дедупликация между источниками и пометка кадровых агентств · группы по давности публикации · возобновляемые запуски · локальные снимки для отслеживания новых и снятых вакансий · **MCP-сервер**, который ваш ИИ-ассистент вызывает напрямую. Полный список изменений — в [CHANGELOG.md](CHANGELOG.md).

> ⚠️ Читаются только **вакансии, которые компании публикуют сами**: никаких резюме и персональных данных, никакого контента за входом в аккаунт, и работа останавливается при любой проверке на бота. См. «Ответственное использование» ниже.

## Возможности

| Возможность | Что делает |
|---|---|
| **По компании** | Достаточно названия: сначала справочник (~90 000 компаний в 24 ATS), иначе перебор распространённых систем; или точно через `--ats система slug` |
| **По многим компаниям** | `--board` по стране / ключевому слову / последним N дням: freehire, общий поиск Workable, государственные базы, площадки удалённой работы; несколько источников сразу, с дедупликацией |
| **Давность** | Каждая вакансия помечается 0–3 месяца / 3–6 месяцев / больше 6 месяцев / без даты; `--board` по умолчанию показывает последние полгода |
| **Агентства** | Помечает вакансии от хедхантеров и кадровых агентств (поле `agency`); `--no-agency` их убирает |
| **Возобновление** | Если один источник упёрся в лимит или упал, остальные продолжают; та же команда с `--resume` докачивает только недостающее |
| **Локальные снимки** | `--save` пишет в локальный SQLite с датами первого/последнего появления; `--history` показывает новые и снятые вакансии по запускам |
| **MCP-сервер** | `--mcp`: Claude Code / Codex и др. вызывают напрямую (компания, поиск вакансий, справочник) |
| **Китай: 170 компаний** | `--local`: три универсальных парсера (Feishu Hire / Moka / Beisen) + 6 собственных порталов крупных техкомпаний |
| **Частные плагины** | Источники, условия которых не подходят для публичного распространения, хранятся в вашей папке (`--plugins`), вне репозитория |
| **Только stdlib** | Ноль зависимостей (только парсеру Moka нужен `pycryptodome`); работает на любом `python3` |

## Быстрый старт

```bash
git clone https://github.com/simonlin1212/Hiring-Radar.git
cd Hiring-Radar
python3 hiring_radar.py --directory-update   # скачать справочник (~90 000 компаний, хранится локально; необязательно, но рекомендуется)
python3 hiring_radar.py --list               # список всех источников
```

```bash
# 1) По компании: достаточно названия
python3 hiring_radar.py anthropic --keyword research
python3 hiring_radar.py xero                         # найдено в справочнике → нужная система
python3 hiring_radar.py --find xero                  # только показать, какая у неё ATS
python3 hiring_radar.py --ats teamtailor <slug>      # задать систему и аккаунт
python3 hiring_radar.py --workday host,tenant,site

# 2) По многим компаниям: страна + ключевое слово + период
python3 hiring_radar.py --board freehire --country AU,NZ --keyword receptionist,bookkeeper
python3 hiring_radar.py --board freehire,workable --country AU --max 0 --json > au.json   # без ограничения
python3 hiring_radar.py --board jobtech --keyword ekonomiassistent --recent-days 30       # госбаза вакансий Швеции
python3 hiring_radar.py --board all --keyword "AI engineer"                              # 4 площадки удалённой работы

# 3) Продолжить после обрыва / снимки
python3 hiring_radar.py --board freehire,workable --country AU --max 0 --json --resume > au.json   # после обрыва: точно те же параметры, что выше, плюс --resume
python3 hiring_radar.py anthropic --save          # следующий запуск покажет новые/снятые вакансии
python3 hiring_radar.py --history

# 4) Китайские компании
python3 hiring_radar.py --local agibot --keyword 机器人      # AgiBot (Feishu)
python3 hiring_radar.py --local cambricon --keyword 大模型   # Cambricon (Moka; pip install pycryptodome)
python3 hiring_radar.py --local tencent --keyword 算法       # Tencent (собственный портал)
```

**Частые параметры**: `--keyword a,b` (любое совпадение) · `--recent-days N` (0 = без ограничения) · `--country AU,NZ` · `--max N` (предел на источник, по умолчанию 1000, 0 = без предела) · `--no-agency` · `--json` · `--limit N` · `--debug`

**Переход с v1**: `--board` теперь по умолчанию берёт только последние 183 дня, не больше 1000 вакансий на источник, и убирает дубли между источниками; чтобы получить результаты как в v1, добавьте `--recent-days 0 --max 0 --no-dedupe`.

**Переменные окружения**: `HIRING_RADAR_HOME` (справочник, снимки, состояние возобновления; по умолчанию `~/.hiring-radar`) · `HIRING_RADAR_DELAY` (минимум секунд между двумя запросами к одному сайту; по умолчанию 0,3) · `HIRING_RADAR_PLUGINS` (папка частных плагинов) · `HIRING_RADAR_INSECURE=1` (отключить проверку сертификатов, только за перехватывающим прокси)

Коды выхода: `0` — успешно; `1` — ошибка; `3` — результат неполный: источник остановился из-за ошибки (полученное всё равно выводится; повторите ту же команду с `--resume`), лимит постраничной выдачи источника отдал только часть (возобновление не поможет; сузьте запрос) или `--directory-update` не смог скачать часть систем (их старые списки сохранены).

## Для ИИ-ассистентов (MCP)

```bash
claude mcp add hiring-radar -- python3 /path/to/Hiring-Radar/hiring_radar.py --mcp
```

Пять инструментов: `company_jobs` (одна компания) · `search_jobs` (по многим компаниям) · `find_company` (справочник) · `list_sources` · `job_history`. Описания вакансий в результатах MCP обрезаются до 800 символов; полный текст — через командную строку с `--json`.

## Поля вывода

15 полей v1 не меняются: `title · company · dept · team · location · remote · type · date · date_updated · req_id · comp (зарплата) · jd (полное описание) · url · apply_url · id`

v2 добавляет 9: `country` (код страны) · `source` (источник) · `age` (группа 0-3m/3-6m/6m+/unknown) · `agency` (найденный признак агентства) · `also` (другие источники с той же вакансией после дедупликации) · `industry` · `size` (размер компании, если источник его даёт) · `first_seen` · `last_seen` (только со снимками)

Обёртка `--json`: `source · total · matched · jobs` (как в v1) + `version · query · ages · sources · incomplete · candidates · saved`.

## Как это работает

```
Название компании / страна + ключевое слово
        │
        ▼
┌─────────────────────────┐
│ Выбор источников         │  По компании: справочник → открытые интерфейсы 24 ATS
│                         │  По многим: freehire / Workable / госбазы / удалёнка / плагины
│                         │  Китай: Feishu / Moka / Beisen / собственные порталы
└──────────┬──────────────┘
           │  Сеть: честное представление, темп по сайту, ожидание при 429, остановка при 403 или проверке на бота
┌──────────▼──────────────┐
│ 24 поля + давность       │  Фильтры по слову / стране / последним N дням; дедупликация; пометка агентств
└──────────┬──────────────┘
      ┌────┴─────┬──────────────┐
      ▼          ▼              ▼
  Терминал   --json (полный)  Снимки / MCP
```

| `workable` | Весь мир | Общий поиск Workable, фильтры по стране / слову |
| `jobtech` | Швеция | Открытые данные шведской службы занятости, полные описания |
| `mycareersfuture` | Сингапур | Государственный портал вакансий Сингапура, с зарплатой, без описаний |
| `arbeitsagentur` | Германия | Федеральное агентство по труду Германии, без описаний |

**Китай: 170 компаний (`--local`)**: Feishu Hire (Li Auto / XPeng / NIO / AgiBot / Moonshot AI / MiniMax / Zhipu…) · Moka (Hypergryph / Cambricon / High-Flyer / SHEIN…) · Beisen (Dreame / Chery / Leapmotor / BOE / SANY…) · собственные порталы (Tencent / NetEase / JD / Baidu / ByteDance / Unitree). Полный список: `--list`.

**Не поддерживается / известные ограничения**
- **Paycom**: его robots.txt не разрешает доступ к списку вакансий, поэтому он не читается.
- **iCIMS**: `datePosted` на его страницах генерируется системой (текущее время минус два года), поэтому инструмент берёт дату обновления из карты сайта. К датам публикации iCIMS, собранным другими инструментами, относитесь осторожно.
- В справочнике много неактивных аккаунтов — компания без вакансий это нормально; одноимённые компании могут совпасть — при нескольких совпадениях выводятся все кандидаты.
- Дедупликация идёт по стране + компании + названию вакансии: одна и та же должность компании в нескольких городах одной страны станет одной строкой.

> **О Moka (честно)**: интерфейсы Moka слегка обфусцируют ответы на стороне фронтенда (AES-128-CBC, ключ и IV поставляются вместе с публичным фронтендом). Инструмент использует эти публичные значения, чтобы получить ровно тот же публичный список вакансий, что видит браузер, — без взлома входа и обхода аутентификации. Строго говоря, это «повтор обработки фронтенда», чуть серее, чем чтение обычного JSON; только для локальных исследований, на ваш риск. Для самой чистой позиции удалите все строки `moka` в `parsers/companies.seed` и встроенные строки `yostar`/`tesla-cn` в `radar/local.py`.

## Частные плагины

Для крупных площадок, чьи условия не подходят для публикации кода сбора, напишите собственный плагин вне репозитория:

```bash
python3 hiring_radar.py --plugins ~/my-plugins --board myboard --country AU
```

Каждый файл `.py` в папке, не начинающийся с `_`, — это источник с `NAME`, `DESC`, `FILTERS` и `pages(q, state=None)` (тот же интерфейс, что в `radar/boards/`); в файлах с `_` в начале можно держать общий код. Плагины работают с вашими правами, и за соблюдение условий посещаемых сайтов отвечаете вы.

## Отраслевой сигнал

Найм — **опережающий индикатор**: где компания расширяется, в каком направлении и на какой стадии, часто видно за месяцы до отчётности. Ищут инженеров линии — линия строится; ищут качество/обслуживание — готовится стабильное производство; ищут ночную смену — близок рост объёмов. Делайте регулярные снимки через `--save` и смотрите ритм через `--history`.

> ⚠️ **Найм ≠ выпуск**: вакансии — это вложения, а не результат; «нанимает» может означать и кадровый резерв, и обратный сигнал. Воспринимайте выводы как сигналы, а не инвестиционные рекомендации.

## Структура проекта

```
Hiring-Radar/
├── hiring_radar.py     # точка входа командной строки (синтаксис команд v1 не изменился)
├── radar/              # основной пакет
│   ├── http.py         # сеть: честное представление, темп, ожидание, остановка при блокировке
│   ├── schema.py       # единые поля, даты, группы давности
│   ├── ats/            # по компании: один файл на ATS
│   ├── boards/         # межкомпанийные источники
│   ├── directory.py    # справочник компаний (скачивается при запуске)
│   ├── process.py      # дедупликация, пометка агентств
│   ├── sweep.py        # сбор из многих источников, возобновление
│   ├── store.py        # локальные снимки (SQLite)
│   ├── local.py        # парсеры Китая / собственных порталов
│   ├── plugins.py      # загрузчик частных плагинов
```

## Технологии и зависимости

- **Python 3.8+**, ядро только на стандартной библиотеке (urllib / json / re / ssl / argparse / sqlite3 / xml.etree)
- **`pycryptodome`**: только для парсеров Moka (`pip install pycryptodome`)
- Нужен интернет (для некоторых зарубежных сайтов может понадобиться прокси); SSL-сертификаты по умолчанию проверяются, за перехватывающим прокси задайте `HIRING_RADAR_INSECURE=1`
